# 🪔 Design Your Diwali - Virtual House Decoration

A vibrant, interactive web application celebrating Diwali by letting you decorate your virtual house with lights, rangoli patterns, and fireworks in real-time!

## ✨ Features

### 🏮 Four Interactive Rooms
- **Living Room** - Main gathering space
- **Entrance** - Welcome guests with dazzling decorations
- **Bedroom** - Cozy personal space
- **Balcony** - Showcase to the neighborhood

### 💡 Lighting System
- Add multiple colored lights to any room
- Choose from 6 vibrant colors:
  - Gold (Classic Diwali)
  - Deep Red (Traditional)
  - Turquoise (Modern)
  - Magenta (Bollywood Vibes)
  - Saffron (Patriotic)
  - Deep Purple (Royal)
- Lights glow and flicker with authentic animation

### 🎨 Rangoli Drawing
- Draw beautiful rangoli patterns freehand
- 6 traditional colors to choose from
- Express your creativity
- Clear and redraw as needed

### ✨ Fireworks Effects
- Launch spectacular fireworks explosions
- Realistic particle physics and gravity
- Multiple bursts for maximum celebration
- Coordinated fireworks shows

### 📊 Real-Time Statistics
- Track active decorations
- Count total lights placed
- Monitor total decorations across all rooms

## 🎨 Design Aesthetic

This project celebrates **Indian Retro Pop Art** with:
- Bold, vibrant color palette inspired by vintage Indian advertising
- Strong typography with dramatic text shadows
- Authentic Diwali celebration vibes
- Smooth animations and hover effects
- Fully responsive design for all devices

## 🚀 How to Use Locally

1. **Open the website** - Just open `index.html` in any modern web browser
2. **Select a room** - Click on any of the four rooms to start decorating
3. **Add lights** - Click "Add Lights" button and choose your color
4. **Draw rangoli** - Click "Draw Rangoli" and paint beautiful patterns
5. **Launch fireworks** - Click "Launch!" for instant celebration
6. **Clear decorations** - Use the clear buttons to start fresh

## 🚀 Deploy to Vercel

### Option 1: One-Click Deploy (Easiest)
1. Push your changes to GitHub (already done!)
2. Go to [vercel.com](https://vercel.com)
3. Click "New Project"
4. Select your `design-your-diwali` repository
5. Click "Deploy" - Vercel will automatically detect it's a static site
6. Your site will be live in seconds! 🎉

### Option 2: Deploy via Vercel CLI
```bash
# Install Vercel CLI if you haven't already
npm i -g vercel

# From the project directory
vercel

# Follow the prompts to link to your account and deploy
```

### Option 3: GitHub Integration
1. Connect your GitHub account to Vercel
2. Every push to your repository triggers automatic deployment
3. Pull requests get automatic preview deployments

### Environment Variables
No environment variables needed - this is a pure static site!

### Custom Domain
After deployment:
1. Go to your Vercel project settings
2. Add your custom domain in "Domains"
3. Update your DNS settings
4. Done!
